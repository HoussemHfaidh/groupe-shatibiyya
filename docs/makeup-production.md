# Rattrapage — import image et Excel, 14 octobre 2026

La section التدارك garde son fonctionnement de suivi et de validation. Le professeur sélectionne une image JPG/PNG/WebP ou un tableau Excel XLSX/XLS puis clique sur نشر التدارك. La liste des élèves avec champs de saisie manuelle a été supprimée. La lecture du fichier remplit automatiquement les dettes ; aucune étape de ressaisie ni d'aperçu supplémentaire n'est imposée.

Les images doivent présenter le tableau complet avec ses quatre colonnes (nom, test, présence, absence) et des bordures lisibles. Le traitement local repère les cellules, lit les chiffres et noms arabes, puis rapproche les noms de la liste du groupe. Les fichiers Excel sont lus par leurs en-têtes, quel que soit l'ordre des colonnes. Les traits d'union séparent des cours explicitement listés : 108-111 signifie 108 et 111, sans inventer 109 ou 110. Les noms impossibles à rapprocher, cellules non lisibles et formats invalides bloquent tout l'import avec un message ; aucune écriture partielle. Les fichiers ne sont pas envoyés à un service OCR. Les bibliothèques et le modèle arabe sont hébergés avec le site.

Stockage isolé dans config/makeup et config/groups/group2/makeup, avec les permissions existantes. Dette unique par élève et cours, motifs fusionnés et validations conservées sans expiration hebdomadaire. Les imports restent additifs, ne rouvrent pas les cours déjà validés et utilisent des ETags. Un changement de groupe annule une lecture en cours. Une erreur conserve le fichier sélectionné pour réessayer. Aucune liaison automatique à حالة الطلاب n'est ajoutée.

Validation : 57 tests de modèles ; publication XLSX dans le groupe 1 et XLS dans le groupe 2, réimport sans doublon, fichier invalide sans mutation, changement de groupe en cours de lecture ; test des rappels et validations élèves. Les deux images fournies ont été lues et publiées dans une base simulée via le même bouton, puis les noms/cours/motifs comparés aux transcriptions vérifiées (13 dettes chacune). Vérification visuelle mobile. Les images et listes nominatives de test restent hors Git. Aucune donnée de production n'est modifiée pour les tests ou par ce déploiement.

L'historique initial du groupe 1, importé le 13 octobre, reste inchangé. Les limites d'autorisation serveur restent celles des chemins config existants. Les anciennes pages ouvertes nécessitent un rechargement.
