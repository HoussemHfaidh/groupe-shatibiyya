# Présences : reconnexions et fusion — 11 octobre 2026

Reconnaissance générale, sans règle liée à un participant précis : noms normalisés,
correspondances du groupe, suffixes d'appareil reconnus, email commun et choix du professeur.
Les correspondances explicites du professeur priment. Les identités ambiguës restent
à vérifier. Les emails du CSV sont désormais conservés dans les données originales.

Dans « تصحيح الأسماء ودمج الاتصالات وحالات الخروج », chaque ligne permet de corriger
le nom, choisir un autre participant et fusionner leurs connexions après confirmation.
Le professeur peut annuler le dernier rapprochement. Les données originales restent
conservées ; les intervalles sont réunis sans double comptage puis limités aux périodes
de présence du professeur. Les indicateurs manuels sont conservés.

« إعادة حساب الجلسة ومطابقة الاتصالات » applique les règles aux imports déjà enregistrés.
Les correspondances sont mémorisées pour ce groupe dans ce navigateur, conformément
au stockage existant de الحضور. Une nouvelle importation réutilise ces correspondances.
