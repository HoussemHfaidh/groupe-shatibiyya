الشاطبية - حرز الأماني

Suivi automatique des élèves

Les élèves envoient leur état depuis un portail web. Le professeur applique les réponses, exporte le tableau en image, puis partage seulement l'image sur WhatsApp. يرسل الطلاب حالتهم عبر البوابة، ثم يطبّق الأستاذ الإجابات ويصدر الجدول كصورة.

Portail / بوابة الطالب

Réponses des élèves / إجابات الطلاب

Les élèves remplissent le portail. Ici, le professeur récupère les réponses, puis applique au tableau : ceux qui n'ont rien envoyé passent automatiquement en rouge. هنا يسترجع الأستاذ الإجابات ويطبّقها في الجدول.

Source : navigateur local. Ajoutez l'URL Firebase. المصدر: المتصفح المحلي. أضف رابط Firebase.
Import manuel / إدخال يدوي
Aucun message analysé pour le moment. لم يتم تحليل أي رسالة بعد.

Configuration / الإعدادات

Ajoutez les élèves et les semaines. أضف الطلاب والأسابيع.

Tableau hebdomadaire / الجدول الأسبوعي

Cliquez sur une cellule pour changer manuellement son état : vide, fait, rattrapage, non fait. اضغط على الخانة لتغيير الحالة يدويًا.

متابعة حفظ الشاطبية
10 lignes par semaine / 10 أبيات أسبوعيًا

Ordre de passage / ترتيب التسميع

L'ordre est construit avec les élèves détectés comme prêts pour la semaine sélectionnée. يتم ترتيب الطلاب الجاهزين للأسبوع المختار.
